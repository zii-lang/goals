# Zirsakht

[zirsakht](https://github.com/zii-lang/zirsakht) provides shared infrastructure
for the Z programming language and its toolchain.

It is responsible for providing common functionality that can be reused
across Z projects, avoiding duplicated infrastructure and maintaining
consistent behavior.

## Goals

Zirsakht should provide the following:

- **Logging:** A unified logging system for Z tools and libraries.
- **Source Management:** Infrastructure for managing source files, source
  locations, and source-related information.

## Future Goals

Additional infrastructure may be introduced as the Z toolchain evolves.
